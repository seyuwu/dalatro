# DALATRO — Dota × покер × Balatro

Браузерный рогалик: собираешь тимфайт из героев как покерную комбинацию,
**Сила × Множитель** бьёт по башне врага. Вертикальный слайс v0.1: 1 акт,
12 героев (ростер 40), 17 предметов с редкостями, секретный шоп с панелью
билда, Roshan с Aegis.

![Шоп](docs/screenshots/05_shop.png)

## Запуск

**Вариант 1 — двойной клик:** открыть `dist/index.html` — вся игра одним
файлом, работает без сервера (портреты героев подгружаются с CDN Valve,
офлайн автоматически включаются SVG-сигилы).

**Вариант 2 — разработка:**

```bash
node serve.js     # http://localhost:8000
npm test          # 37 тестов движка
npm run build     # пересборка dist/index.html
```

Ноль зависимостей.

## Как играть

1. Выбери 1–5 героев — **порядок клика = порядок в бою** (позиции важны).
2. Превью показывает весь стек срабатываний и точный урон до коммита;
   лотерейные криты помечены 🎲.
3. Комбо: пара — дуо, сет — ганг, стрит — смок на Рошана, флеш — тимфайт
   атрибута, фулл-хаус — 4 protect 1.
4. 4 боя на волну, 3 ТП-сброса. Оверкилл → золото (с затуханием), точный
   ласт-хит +5. Провал волны = −1 казарма (всего 6).
5. Шоп: 5 предметов, редкости common/rare/epic, локи, продажа, панель
   **ТВОЙ БИЛД** и разбор «что предмет даст твоему забегу».
6. Divine Rapier: ×2 урона, но при провале её подберёт враг (твой урон по
   нему ×0.5), пока не отбьёшь.
7. Забег детерминирован сидом: `DALATRO-SLICE1`. Автосейв в localStorage —
   обновление страницы не теряет забег; ⏏ в хедере бросает забег.
8. Клавиша **D** / ⚙ — песочница (+1000g, правка башни, лог событий).

## Золотое правило

> **Контент никогда не мутирует GameState напрямую.** Контент декларирует
> условия и эффекты. Движок их разрешает. State меняет только движок.

Новый герой/предмет/босс = запись в `src/content/*.js`, ноль правок движка.
