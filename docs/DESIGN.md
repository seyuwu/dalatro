# DALATRO — Дизайн-философия

Документ фиксирует **почему** механики устроены именно так. Реализованные
утверждения помечены ✅, будущие — ⬜; ничего из ⬜ не считается работающим
(инвентарь актуального — CONTENT.md, планы — ROADMAP.md).

## 1. Ядро

**Урон = Сила × Множитель.** Игрок собирает из 7 карт команду 1–5 героев;
порядок выбора = позиции в тимфайте; лучшая покерная комбинация становится
ударом по башне. ✅

> **Каждая механика должна быть простой. Сложными должны быть
> взаимодействия между механиками.**

Глубина — не в сложности отдельных правил, а в том, что одна и та же карта
меняет роль в зависимости от предметов, позиции, атрибутов, комбо и
состояния башни.

## 2. Замкнутый контур ✅

```
Poker → Position → Attribute/Rank → Hero abilities → Items
      → Modifiers → Damage → Overkill/Last Hit → Gold
      → Shop → Build → снова Poker
```

Цель развития — углублять этот контур, а не добавлять механики ради
количества.

## 3. Шесть фундаментальных систем ✅

| Система | Отвечает за | Где живёт |
|---|---|---|
| Resolution Engine | что и в каком порядке происходит | engine/combat-фазы |
| Positions / Order | где карта и кто её соседи | слоты 1–5, SLOT_IS/COPY_ATTRIBUTE |
| Modifiers | какие правила сейчас изменены | волны/боссы: Armor/Glyph/Aegis |
| Economy | что игрок может себе позволить | золото, оверкилл, шоп |
| Card Lifecycle | где карта: колода/рука/сыграна/сброс | deck.js; ⬜ уничтожение/buyback |
| Tags / Attributes | к чему карта относится и какие условия выполняет | атрибуты, ⬜ роли |

Пересечения систем и создают глубину.

## 4. Эталонная цепочка: Morphling ✅

Morphling копирует атрибут соседа **до** детекции (PRE_DETECT), поэтому:

```
позиция → изменение атрибута → новое комбо → условие Zeus → +множитель
        → предметы → урон → оверкилл → золото → шоп
```

Morphling + Zeus — эталон хорошей синергии: каждый полезен сам по себе,
вместе дают новое поведение. С v0.1.2 цепочка **подсвечивается игроку**:
если Zeus сработал только благодаря копии, в стеке появляется 🔗-шаг.

## 5. detectPower ≠ real Power ✅

Butterfly (±1 ранг слабейшей), Shadow Blade (±1 сильнейшей) и иллюзии Manta
меняют то, как карта видна покерному детектору, не трогая её реальную силу.
Класс взаимодействий: «карта выглядит одним для покера и другим для урона».

## 6. Предметы: статические vs rule-breaking ✅

Статические усиливают билд. Rule-breaking (Manta, Butterfly, Shadow Blade,
BKB, Rapier, Refresher) меняют саму игру — они обязаны давать главные
«Balatro-моменты». Ценность предмета — не цифра, а один из четырёх видов:
вероятность пика (Daedalus), пространство комбинаций (Manta), кратность
реализации (Refresher), выживаемость билда (BKB).

## 7. Шоп — главный decision point ✅

Вопрос игрока в шопе: «что этот предмет сделает с моим билдом?». Инструменты
ответа: панель **ТВОЙ БИЛД** (прогресс направлений), **ЛУПА** (что предмет
даст именно этому забегу), редкости/категории, локи, реролл. Направления
билдов намеренно конфликтуют: Power (Heart/Radiance/Battle Fury) против
Mult (Daedalus/Satanic/Octarine) против Rules (Manta/Butterfly/Shadow Blade)
против Economy (Midas/Vladmir's).

## 8. Экономика как второй слой ✅

Оверкилл конвертируется в золото с затуханием, точный Last Hit бонусует,
большой урон никогда не ошибка. Крит (Daedalus) превращает возможный
ласт-хит в возможный оверкилл — это риск экономической оптимизации, а не
баг системы. Rapier добавляет ось риска: провал волны → предмет у врага →
×0.5 к урону по нему; казармы — легальная страховка, а не просто жизни.

## 9. Card Lifecycle

✅ Deck → Hand → Played → Discard. Две реакции на сброс уже есть:
CM (+2 золота) и Pudge (50% возврат) — discard становится ресурсом.
⬜ Destroyed → Graveyard → Buyback/Resurrection: золото получит
альтернативную стоимость «предмет сейчас vs карта назад».

## 10. Теги ⬜

Роли Carry/Support/Initiator не встраиваются в формулу урона — только
способности и условия (`HAS_TAG`). Карта ценна ролью в команде, а не силой.

## 11. Семь классов синергий

1. **Transform** — меняет состояние другой: Morphling → атрибут → Flush ✅
2. **Amplify** — усиливает результат: фулл-хаус → Daedalus ✅
3. **Enable** — делает возможной: Manta → недостающая карта ✅
4. **Recycle** — возвращает в систему: discard → Pudge ✅
5. **Convert** — ресурс в ресурс: оверкилл → золото → шоп ✅
6. **Counter** — ответ на механику: Armor → BKB ✅
7. **Risk conversion** — безопасность в силу: Rapier ✅

Лучшие билды объединяют несколько классов сразу.

## 12. Четыре свойства хорошей синергии

1. Обе части полезны отдельно (Morphling без Manta — всё ещё карта силы 5).
2. Вместе появляется новое поведение, а не «10+10=20».
3. Игрок может подготовиться: позиции, превью, бейджи башни, лотереи 🎲.
4. Есть способ сломать связку — иначе она становится единственной стратегией.

Анти-синергии (Power-билд против ласт-хита, Rapier против осторожности) —
не баг: они заставляют выбирать направление.

## 13. Боссы = проверка билда 🚧 (Techies ✅, v0.2)

Принцип: **босс создаёт проблему → шоп продаёт ответ**. Techies — первая
реализация: мины закрывают 2 карты руки каждый бой, шоп отвечает Sentry
Ward (6g, точечная контра) или BKB (7g, универсальная). Aegis реализован
как модификатор с эффектом REVIVE; мины пока назначаются движком
(Game.assignMines) — при появлении боссов с дебаффами уйдут в
контент-триггеры. Дальше: Tinker → фиксатор порядка, Invoker → адаптивный
билд, Midas → ценность discard.

## 14. Одна карта — несколько ролей

Эталонная траектория игрока: Morphling «нужен для Flush» → с Manta «создаёт
ещё одну карту атрибута» → с ранговыми предметами «работает и на Straight» →
с Daedalus «пик разгоняется через Mult». Карта раскрывает функции по мере
билда — это основная модель развития Dalatro.

## 15. Критерий успеха

Не количество механик, героев или предметов. Вопрос:

> **«Купил ли игрок предмет, потому что понял, как он взаимодействует
> с его билдом?»**

«Беру Manta, потому что с Morphling сделаю вот это» — система работает.
«Daedalus даст больше цифры» — синергетический слой пока мелковат.

## 16. Архитектурный вывод ✅

Отдельного кода для комбинаций не существует: универсальные
**Events → Conditions → Effects → Resolution**. Новая синергия собирается из
`позиция + условие + событие + эффект + существующий объект`. Контент только
объявляет правила, движок исполняет, State меняется только через Engine:
**Content never mutates GameState directly.**

Путь игрока: «я понял правило» → «я понял, как два правила взаимодействуют» →
«я не ожидал, что эти три вещи соединятся — и это сделал я».
