# prototype — formation-v2 (исторический стенд)

Прототип замены ядра скоринга: **Формация + Связки + Броня** вместо покерных рук.
Версия v2 — результат ревью v1 (см. `docs/REDESIGN_ANTI_BALATRO.md` §12).
> Каноничная система теперь живёт в `src/` (state.rules = "formation"); прогон ниже грузит src. Прототипные копии оставлены для истории.

Собрана под одну гипотезу: **«Интересно ли игроку собирать и переставлять
тимфайт ради формации?»** Всё, что на неё не работает, отложено.

```bash
node prototype/run.mjs            # сравнение старой и новой систем + кривая + 37 тестов
node prototype/run.mjs --tests    # только тесты
node tests/run.js                 # регресс боевого кода (66 тестов, не менялся)
```

Прототип грузит реальный `src/` через vm (тот же список файлов, что
`tests/run.js`) и держит контракт `PokerSys.evaluate` — переезд в `src` за
фич-флагом будет миграцией данных, а не переписыванием движка. **`src/` не тронут.**

## Что внутри

| Файл | Что это |
|---|---|
| `content_formation.js` | Данные: 10 формаций (5 позиционных — читают порядок слотов), 7 связок, защита башен (armor/mr) |
| `formation.js` | `FormationSys`: детекция по detectPower-рангам, выбор формации по **максимуму итогового урона**, связки складываются все, митигейт типов урона, `alternatives[]`, `bestSwap()` |
| `compare.js` | 8 сценариев «старое vs новое» (ставка ×1.25 у обеих), панель альтернатив, кривая баланса по 5 башням |
| `formation.test.js` | 37 тестов в harness-стиле `tests/run.js` |
| `run.mjs` | vm-раннер без зависимостей |

## Правило выбора формации (ключевое отличие от v1)

1. найти все валидные формации;
2. для каждой посчитать полный ожидаемый результат — итоговый урон
   (база + связки + Σ сил карт, ставка, тип урона против брони цели);
3. выбрать максимум;
4. ничья — предпочесть позиционную формацию.

Плюс данные для UI: `evaluate(cards, { defense, commit }).alternatives` —
отсортированный список («Клин 225 / Стена 212 / Отряд 154»), и
`bestSwap(cards, opts)` — «переставь Sven ↔ Crystal Maiden → Клин 225 (+13)».

## Чего в v2 нет сознательно

- **Роли** — вернутся после ручной разметки `hero.roles` (ROADMAP, акт 3);
  фоллбек v1 делал «Инициацию» дублем «Силы» и искажал все числа.
- **Контрпик** — заморожен до акта 2 (риск «Excel»).
- **«Гранд-финал»** — нереализуем без ролей (нужно 5 разных).
- **Desolator / Pipe / Hood**, вторые ступени связок — ось брони уже есть,
  предметы добавим при переезде в `src`.

## Известные хвосты перед переездом в `src`

1. Перекалибровка предметов (Heart +25, Kaya +10 обесценились на новом поле урона).
2. HP/броня башен — кривая v2 («T1–T2 без предметов, T3 требует билда»)
   совпадает с таргетом `BALANCE.md`, но это надо подтвердить A/B.
3. Числа связок/формаций финализировать только после плейтеста гипотезы.
