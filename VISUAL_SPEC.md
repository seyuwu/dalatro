# DALATRO — Visual Spec

**Направление:** Balatro readability × Dota 2 visual language × roguelike
panels. Тёмный синевато-графитовый фон, золото как акцент прогресса, грёбаные
углы (`clip-path`-октагоны) как подпись UI, большие читаемые числа.

## IP-политика (важно для публичного релиза)

Портреты героев в прототипе грузятся с **публичного CDN Valve**
(`cdn.cloudflare.steamstatic.com/.../dota_react/heroes/<name>.png`) — это
фанатское использование, недопустимое в коммерческом релизе.

Архитектура готова к замене: единственная точка — `src/ui/art.js`:
- `DOTA_IMG` — карта heroId → внутреннее имя Steam;
- `heroArt()` кладёт `<img>` **поверх** SVG-сигила с `onerror → remove()`;
  недоступный CDN/запрещённый ассет автоматически откатывается на
  оригинальную стилизацию;
- для релиза достаточно подложить свои файлы в мапу (или заменить `heroArt`
  на локальные ассеты) — UI не меняется вообще.

SVG-сигилы (12 стартовых героев + 4 атрибутные руны-фолбэка) — наша
собственная векторная стилизация в языке «ability icon» Dota: это и есть
заготовка оригинального арт-пула на все 40 карт сетки 10×4.

## Анатомия карты героя

```
┌──────────────────┐
│ NAME         (5) │  header: имя (caps, ≤2 строк) + гем силы (октагон)
│                  │
│    [ PORTRAIT ]  │  арт: портрет (cover, object-position 50% 18%)
│    glow attr     │  поверх радиальное свечение атрибута;
│                  │  под ним SVG-сигил (фолбэк)
│ ✦ ability line   │  полоса способности (только у героев с абилкой)
│      [STR]       │  футер: чип атрибута
└──────────────────┘
```

- 106×156, углы срезаны на 9px, внутренняя рамка 1px rgba(white,.06).
- Выбранная: translateY(-16px) + золотая рамка + glow.
- Дискорд-режим: пунктирная красная обводка.
- Иллюзия (Manta): dashed-рамка, opacity .85.

## Типографика

- System stack: "Segoe UI", system-ui. Никаких веб-шрифтов (file:// offline).
- Числа урона: preview 46px / анимация 88px / weight 900, gold + text-shadow.
- Названия панелей: 12px caps, letter-spacing 2px, золото.
- Имена героев: 9.5px caps, переносятся на 2 строки (не ellipsis — узнавание
  важнее компактности).
- Способности на карте: 9px, золото, одна строка.

## Магазин

- Сетка 5 предложений (196px карточки), верхняя кромка цвета редкости,
  чипы «редкость + категория», гем-медальон 44px с эмодзи предмета.
- Правая колонка 330px: «ТВОЙ БИЛД» (строки с прогресс-барами) и «ЛУПА»
  (разбор пиннутого предмета: правила + «что даст твоему забегу»).
- Lock-кнопка на каждом предложении; залоченная карточка получает золотой
  контур.

## Анимации (все дешёвые, 120–500ms)

- stepIn: шаги стека выезжают слева в оверлее и в превью.
- Панч урона: scale(.4→1) на cubic-bezier(.2,1.6,.4,1).
- Карта: hover -6px, выбор -16px.
- HP-бары: width .5s ease.
- Правило: анимация не должна мешать чтению стека; никаких петель.
